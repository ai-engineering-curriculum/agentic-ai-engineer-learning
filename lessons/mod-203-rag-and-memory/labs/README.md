# Labs for mod-203-rag-and-memory (RAG & Memory Implementation)

Labs are short, guided, observational sessions — distinct from the [exercises](../exercises/), which are longer, open-ended builds. Each lab targets one chapter and complements (does not duplicate) the exercises.

- [Lab 1 — Watch Episodic Memory Roll Into a Summary](lab-01-watch-episodic-memory-roll-into-summary.md) — ~30 min. Chapter 2's `EpisodicMemory` class in action: feed it a stream of turns, watch the first roll-up fire, and read the exact shape of `context()` at 3, 12, and 50 messages. Pure Python with a stub summarizer — no API — so you can see what moved into the summary and what stayed verbatim. [Exercise-02](../exercises/exercise-02-agent-long-term-memory.md) is where you wire a real summarizer and a long-term tier underneath it.
- [Lab 2 — Prove the Conflict-Resolution Priority Order](lab-02-prove-the-conflict-resolution-priority.md) — ~30 min. Chapter 3's `resolve` function against contrived memory sets, one per signal: recency-decides, source-authority-overrides-recency, confidence-breaks-ties, and the true-tie case the resolver can't fix. Includes the write-side supersede-vs-append comparison. [Exercise-02](../exercises/exercise-02-agent-long-term-memory.md) is where the resolver then runs on a real recall path.
- [Lab 3 — Localize a RAG Fault with the Triad](lab-03-localize-a-rag-fault-with-the-triad.md) — ~45 min. Chapter 4's localization table as a drill: three toy pipelines (retrieval-broken, generator hallucinating, generator answering the wrong question), one triad scorer with stub judges, and the exercise of matching each score pattern to a fault *before* reading the pipeline code. [Exercise-04](../exercises/exercise-04-rag-triad-evaluation.md) is where you swap the stub judges for an LLM judge over your own corpus.
