# Labs for mod-204-multi-agent-implementation (Multi-Agent Systems Implementation)

Guided, step-by-step practice for [mod-204](../README.md). Labs are shorter and more scaffolded than the module's [exercises](../exercises/) — they warm you up for each chapter's pattern against mocked agents, so you can see the control flow before Exercise 01–04 ask you to wire the same shape against a real model.

| # | Lab | Duration | Covers |
|---|---|---|---|
| 01 | [Fan Out and Gather with Mock Workers](lab-01-fan-out-and-gather-with-mock-workers.md) | ~45 min | [Chapter 1](../01-orchestrator-worker.md) |
| 02 | [Type and Validate A2A Messages at the Boundary](lab-02-validate-a2a-messages-at-the-boundary.md) | ~40 min | [Chapter 3](../03-inter-agent-communication.md) |
| 03 | [Drive the Evaluator-Optimizer Loop with a Scripted Critic](lab-03-drive-the-evaluator-optimizer-loop-with-a-scripted-critic.md) | ~45 min | [Chapter 5](../05-evaluator-optimizer-loop.md) |

Suggested order: run each lab **before** the exercise that covers the same chapter. Lab 01 is a precursor to [Exercise 01](../exercises/exercise-01-orchestrator-worker-build.md); Lab 03 is a precursor to [Exercise 04](../exercises/exercise-04-evaluator-optimizer-loop.md). Lab 02 stands alone — no module exercise covers Chapter 3 directly, so this lab is its hands-on companion.
