# Labs for mod-201-agent-fundamentals (Agent Fundamentals: The Reason-Act Loop)

Guided, step-by-step practice for [mod-201](../README.md). Labs are shorter and more scaffolded than the module's [exercises](../exercises/) — they warm you up for each chapter's exercise rather than replacing it.

| # | Lab | Duration | Covers |
|---|---|---|---|
| 01 | [Inspect Messages, Special Tokens, and the Context Budget](lab-01-inspect-messages-tokens-context.md) | ~45 min | [Chapter 2](../02-messages-tokens-and-context.md) |
| 02 | [Trace a ReAct Step with a Mock LLM](lab-02-trace-a-react-step-with-a-mock-llm.md) | ~30 min | [Chapter 3](../03-react-loop.md) |
| 03 | [Your First Native Function Call](lab-03-your-first-native-function-call.md) | ~45 min | [Chapter 4](../04-function-calling.md) |

Suggested order: run each lab **before** the exercise that covers the same chapter. Lab 01 stands alone (no exercise covers Chapter 2); Lab 02 is a precursor to Exercise 01; Lab 03 is a precursor to Exercise 02.
