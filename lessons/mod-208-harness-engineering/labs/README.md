# Labs for mod-208-harness-engineering (Harness Engineering)

Guided, step-by-step practice for [mod-208](../README.md). Labs are shorter and more scaffolded than the module's [exercises](../exercises/) — they warm you up for the mechanics each chapter leans on, so the exercise work is about applying them to a real repo rather than reverse-engineering what the primitive does. Every lab runs offline against a deterministic mock so the shape is visible before you spend a token on it.

| # | Lab | Duration | Covers |
|---|---|---|---|
| 01 | [Feel Specific-Beats-General with a Mock Agent](lab-01-feel-specific-beats-general-with-a-mock-agent.md) | ~45 min | [Chapter 1](../01-what-is-a-harness.md), [Chapter 2](../02-guides-context-and-skills.md) |
| 02 | [Pipe Hook Events to Feel the Contract](lab-02-pipe-hook-events-to-feel-the-contract.md) | ~45 min | [Chapter 3](../03-tools-permissions-hooks.md) |
| 03 | [The JSON Feature List Pattern for Long-Running Work](lab-03-feature-list-pattern-for-long-running-work.md) | ~45 min | [Chapter 4](../04-sensors-feedback-and-evals.md) |

Suggested order: run each lab **before** the exercise that covers the same chapter(s). Lab 01 is a precursor to [Exercise 01](../exercises/exercise-01-harness-a-repository.md); Lab 02 to [Exercise 02](../exercises/exercise-02-guardrail-hooks.md); Lab 03 pairs with the long-running-session half of [Chapter 4](../04-sensors-feedback-and-evals.md) that [Exercise 03](../exercises/exercise-03-harness-eval.md) does not cover (Exercise 03 focuses on the evals half).
