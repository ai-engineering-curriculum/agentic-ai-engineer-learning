# Labs for mod-209-building-custom-harnesses (Building a Custom Agent Harness)

Guided, step-by-step practice for [mod-209](../README.md). Labs are shorter and more scaffolded than the module's [exercises](../exercises/) — they warm you up for the mechanics each chapter leans on, so the exercise work is about applying them to a real harness rather than reverse-engineering what the primitive does. Every lab runs offline against scripted inputs so the shape is visible before you spend a token on it.

| # | Lab | Duration | Covers |
|---|---|---|---|
| 01 | [Drive the Loop with a Scripted Model](lab-01-drive-the-loop-with-a-scripted-model.md) | ~45 min | [Chapter 1](../01-harness-architecture.md), [Chapter 2](../02-the-agent-loop.md) |
| 02 | [Exact-Match Edit and the Read Ledger](lab-02-exact-match-edit-and-the-read-ledger.md) | ~45 min | [Chapter 3](../03-coding-tools.md) |
| 03 | [Clear Tool Results Without Breaking Pairing](lab-03-clear-tool-results-without-breaking-pairing.md) | ~45 min | [Chapter 5](../05-context-compaction-state.md) |

Suggested order: run each lab **before** the exercise that covers the same chapter(s). Lab 01 is a precursor to [Exercise 01](../exercises/exercise-01-build-a-minimal-harness.md); Lab 02 to [Exercise 02](../exercises/exercise-02-coding-tool-suite.md); Lab 03 to [Exercise 04](../exercises/exercise-04-context-and-session-state.md).
