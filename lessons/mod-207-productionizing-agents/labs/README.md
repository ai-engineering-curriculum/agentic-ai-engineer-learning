# Labs for mod-207-productionizing-agents (Productionizing Agents)

Guided, step-by-step practice for [mod-207](../README.md). Labs are shorter and more scaffolded than the module's [exercises](../exercises/) — they warm you up for each chapter's exercise rather than replacing it. Every lab runs offline against a deterministic mock so the primitives are visible before you spend a token on them.

| # | Lab | Duration | Covers |
|---|---|---|---|
| 01 | [Three Endpoint Shapes with a Mock Agent](lab-01-three-endpoint-shapes-with-a-mock-agent.md) | ~45 min | [Chapter 1](../01-agent-apis-and-containers.md) |
| 02 | [Hand-Roll a Replay Journal to Feel Durable Execution](lab-02-hand-roll-a-replay-journal.md) | ~45 min | [Chapter 2](../02-durable-execution.md) |
| 03 | [Cache Reads and Router Escalation with a Scripted LLM](lab-03-cache-reads-and-router-escalation.md) | ~45 min | [Chapter 3](../03-caching-and-routing.md) |

Suggested order: run each lab **before** the exercise that covers the same chapter. Lab 01 is a precursor to [Exercise 01](../exercises/exercise-01-agent-api-deployment.md); Lab 02 to [Exercise 02](../exercises/exercise-02-durable-execution-temporal.md); Lab 03 to [Exercise 03](../exercises/exercise-03-caching-and-routing.md). Chapter 4's HITL persistence is covered directly in [Exercise 04](../exercises/exercise-04-hitl-with-persistence.md), which leans on the durable-execution discipline you'll have felt in Lab 02.
